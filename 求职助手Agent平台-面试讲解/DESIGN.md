## 2. 颜色系统（≤ 4 hex + 中性色）

| 角色 | hex | 面积 | 用途 |
| :--- | :--- | :--- | :--- |
| 主色 | `#0F4C81` | ≤ 40% | 标题、章节大字、架构图线框、柱状图主系列、左栏色块 |
| 辅色 | `#7BA7D9` / 浅底 `#DCE9F5` | ≤ 25% | 卡片底、图表第二系列、分隔线、SVG 次级元素 |
| 强调色 | `#E8590C` | ≤ 10%（Hero 页 ≤ 18%） | 巨型数字、关键数据标注、短横线、优化前后对比的"后值" |
| 中性 | 文本 `#1F2D3D` / 次级 `#5E7B99` / 背景 `#FAFCFE` / 白 `#FFFFFF` | 剩余 | 正文、页脚、页面底色 |

- Supporting 页强调色 ≤ 5%；Hero 页（P1/P7/P14）强调色可到 15-18%。
- 渐变方案：仅章节扉页左栏允许 `linear-gradient(135deg, #0F4C81 0%, #2E6BA8 100%)`；内容页一律纯色平涂。
- 半透明策略：SVG 图示中已走过的流程节点可用 `rgba(15,76,129,0.08)` 浅底；禁止大面积蒙版。

| 层级 | 字号/字重/行高 | 字体 |
| :--- | :--- | :--- |
| 封面主标题 | 72px / bold / 1.2 | 思源黑体（Source Han Sans） |

| 正文 | 20–22px / regular / 1.55 | 思源黑体 |
| 图内标注 | 16–18px / regular / 1.4 | 思源黑体 |
| 脚注/页码 | 12px / regular / 1.4 | 思源黑体 |

- 巨型数字一律用西文字体族（Inter/Helvetica Neue），与中文正文区分字重与字形。
- 全篇仅 2 套字体家族：思源黑体 + Inter/Helvetica Neue。

## 4. 信息密度声明

- 风格：极简蓝白（清爽克制），但**非留白型**——常规内容页留白 ≤ 35%，P7/P14 等视觉高潮页 ≤ 45%。
- 内容页正文 ≥ 180 字（除数据总览页 140 字）；每页 ≥ 1 个视觉锚点（≥ 48px 元素或 ≥ 40% B 区图示）。
- 容器填充率 ≥ 85%；卡片尾部元素 `marginTop:auto` 钉底；兄弟卡三段 y 轴对齐。
