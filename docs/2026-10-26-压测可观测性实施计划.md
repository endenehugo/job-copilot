# 服务器资源监控与后端分段计时 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给压测补上服务器资源采样（单元 A）和后端 chat 请求的分阶段耗时（单元 B），并让压测脚本能把每个请求的耗时与服务端阶段耗时落成 CSV。

**Architecture:** A 是纯标准库的 `/proc` 采样器加汇总器，解析逻辑是纯函数，采样器接受 `proc_root` 参数以便用假目录测试。B 是一个 `ContextVar` 驱动的 `perf_trace` 模块，没有 trace 时 `span` 为空操作；在 `QuotaFallbackMixin` 统一记录 LLM 调用，在 chat 共享流程里手工打点，API 入口开启 trace、写日志、按开关返回 `Server-Timing`。压测脚本解析该响应头写 `_ai_requests.csv`。

**Tech Stack:** Python 3.12 标准库（监控）、FastAPI/LangChain（后端，沿用）、Locust 2.47、PowerShell 启动器、pytest（后端）、unittest（`tools/loadtest`）。

规格：`docs/superpowers/specs/2026-10-26-perf-observability-design.md`

规则：CPU 取 `/proc/stat` 差；进程 CPU% = Δticks / clk_tck / Δt × 100（100 表示满载一个核）；`swapin_ps`、`swapout_ps`、`net_*_bps` 为 Δ/Δt；`swap_used_mb = (SwapTotal - SwapFree) / 1024`；进程读取失败跳过；组内无进程时 `procs=0`、CPU/RSS 为 0；`mysql_query()` 返回 `(threads, slow)` 或 `None`，每 5 秒调一次并缓存，异常吞掉。`main` 参数：`--out`、`--label`（必填）、`--interval`（1.0）、`--duration`、`--wrap`、`--app-root`（`/opt/job-copilot`）、`--mysql-defaults-file`、`--proc-root`（测试用）。前缀 `<out>/server-<label>`；`_server.csv` 已存在返回 2；`<proc_root>/self` 不存在返回 2 并说明需要 Linux，且不创建任何文件；`--wrap` 用 `subprocess.Popen(shlex.split(cmd))`，结束后再采样一次并返回命令退出码；节拍用 `next_t += interval` 固定，`lag_ms = max(0, now - scheduled) * 1000`；每行写完 `flush()`。`_server_meta.json` 含 `hostname, kernel, cpu_count, mem_total_mb, swap_total_mb, systemd(MainPID/ActiveState 或 null), app_commit(或 null), interval_s, monitor_sha256, started_at`。

```python
class PerfTrace:
    trace_id: str; kind: str; attrs: dict; spans: list[dict]
    def total_ms(self) -> float
    def stages(self) -> dict[str, float]      # 顶层阶段名 -> 毫秒；名字取第一个"."之前（db.save->db, tool.x->tool）；llm.call 不计入
    def llm_summary(self) -> tuple[int, float] # (次数, 总毫秒)
    def to_log_dict(self) -> dict              # v,trace_id,endpoint(kind),+attrs,total_ms,stages,llm_calls,llm_ms,spans
    def to_server_timing(self) -> str
@contextmanager
def trace_scope(kind, **attrs) -> Iterator[PerfTrace]   # 退出时输出日志；已有 trace 时直接 yield 外层的，不嵌套
@contextmanager
def span(name, **attrs) -> Iterator[dict | None]        # 无 trace 时 yield None 且不记录；业务异常照常传播，并在 attrs 写 error=类型名
def record_span(name, dur_ms, **attrs) -> None          # 按已测耗时直接登记，parent 取当前栈顶（流式生成器里用）
def record_llm_call(model, dur_ms, *, in_tokens=None, out_tokens=None, fallback=False, error=None) -> None
def current_trace() -> PerfTrace | None
def set_attr(key, value) -> None
def configure_perf_logging() -> None                    # 幂等：app.perf 设 INFO、propagate=False、无处理器时加 stdout 处理器；settings.perf_trace_log 为假则 disabled
```
