# 体验审计清单：慢的地方 & 静默失败的地方

> 审计日期：2026-10-11　范围：`backend/app/`（60 个 py 文件）+ `frontend/src/`（21 个文件）
> 方法：全量通读代码 + grep 交叉验证，未修改任何文件。所有行号均来自实际代码。
> 分级：P0 = 严重阻塞或数据错误且无感知　P1 = 明显卡顿或功能失效　P2 = 边界情况

---

## 结论先行

**"慢"的第一根因不是模型，是一次对话里串行的 LLM 调用次数。** 一条普通消息的耗时结构：

```
[无反馈 15~30s] 检索 + Rerank：最多 16 次串行 LLM 调用   ← 用户看到空白气泡
[有反馈]        首轮流式生成（打字机）                     ← 唯一有反馈的阶段
[无反馈 3~8s]   上下文验证 LLM                            ← 字打完了又卡住，最后闪一下
```

**"静默失败"的第一根因是降级路径与失败路径返回同一个值。** 全项目 13 处 LLM 调用**只有 1 处设置了超时**；大量 `except` 用空列表/0 分/5.0 分/空字符串兜底，HTTP 依然 200、信封依然 `success`。

**还有一个比慢更严重的问题**：JD 分析、项目优化、模拟面试三处的结果**算完后没有任何 UI 渲染出口**——用户等了几十秒只看到一句 toast，然后什么都没有。这不是性能问题，是功能缺口，优化速度也解决不了。

# 修复优先级路线图

## 第一批：先止血（不改架构，收益最大）

1. **A1/A2/A3** — Rerank 改成单次批量 LLM 调用（一次 prompt 给 8~16 篇打分），或直接砍掉 LLM Rerank（阈值 + BM25 融合已够用）。**单这一项把首字节从 15~30 秒降到 1~2 秒。**
2. **A4** — 验证 LLM 改为异步/可选：先 `yield done`，验证结果用后续 SSE 事件补发。
3. **A6** — 加统一 LLM 工厂（`core/llm_factory.py`）统一 timeout + max_retries；前端 axios timeout 从 300000 降到普通 15s / 上传 60s。
4. **B7/B8/B9** — 把 `analysis.analysis`、`analysis.rewrite`、`interview.session/rounds` 接到真实 UI。**否则用户对"慢"和"没提示"的抱怨无法靠性能优化解决。**

## 第二批：让失败可见

5. **B1/B2** — 验证失败必须返回 `hallucination_risk: "unknown"` / `verified: False`；`SourcePanel.vue:7-8` 增加 `unknown` 分支显示"未验证"，而不是落到 `risk-low`。
6. **B42** — 响应信封增加 `degraded: true` + `missing_fields: [...]`。
7. **B3/B4/B5/B17** — `_validate_and_normalize` 增加必需字段校验，缺失即抛错或标记 degraded。
8. **B21/B23/B25/B26** — `client.js` 拦截器按 status 分级处理 401/403/5xx/网络错误并统一提示；`main.js` 注册 `app.config.errorHandler` + `unhandledrejection`。
9. **B24** — 4 个空 catch 区分"无数据"与"请求失败"。
10. **B15/B16** — 打分失败记 warning 并置 `score: None`；lifespan 启动时 `check_all()`，失败则 `/health` 标降级。

## 第三批：并发与渲染

11. **A19** — 流式期间对 `renderMarkdown` 做节流（rAF 或 100ms），`MessageList` 的 deep watch 换成对最后一条消息 length 的浅监听。
12. **A28/B30** — `refreshDetail + resume.load`、多图上传改 `Promise.all`；`select()` 加请求序号或 AbortController。
13. **A13** — 给 `conversation_messages.conversation_id`、`conversation_documents.conversation_id`、`knowledge_entries.status` 加索引。
