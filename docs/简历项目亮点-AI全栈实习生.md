## 三、项目亮点（可直接替换简历）

**项目：AI 求职助手平台（个人项目）** — Vue 3 · FastAPI · MySQL · LangChain · SSE · Pytest · Docker

- **独立全栈交付：** 从前端到后端到部署一个人完成：Vue 3/Vite/Pinia 工作台（ChatGPT 风格界面、会话记录父子树 + 主区多视图、发起对话框），FastAPI 按 API/Schema/Service/Repository 四层组织 34 个业务 API，MySQL 持久化，Docker Compose + systemd/Nginx 部署到云服务器；功能覆盖简历/JD 上传解析、会话级 RAG 问答、模拟面试、简历评分与改写、文档导出。
- **流式体验的前后端协同：** 自研 SSE 事件协议（meta→delta→tool_status→sources→done→verification）并在前端消费：提交瞬间占位气泡、流式结果按场次 ID 比对防串写、done 后整体替换、失败回滚输入框；通过耗时结构分析把首字节 15~~30s 优化到 3.7s（重排单次调用、校验异步补发、摘要增量持久化），模拟面试开场 7.1s→1.4~~2.2s、单轮评价 15.8~~19.7s→2.0~~2.8s（关闭思考模式）。
- **AI 功能全链路集成：** ReAct 工具循环编排 9 个可插拔工具（工具异常字符串回灌不断链）；会话级混合检索（FAISS + BM25 + 三级降级 + listwise 重排 21.4s→3.7s）；模拟面试"题库为主 + 低分追问"（后台异步补题、互斥锁保护题单并发）；自动简历生成——不让模型直出 HTML，先抽取结构化 JSON（约 1.5k token）再走固定模板渲染，相比直出（15~25k token）截断风险低一个量级，改字段可零 LLM 成本重渲染。
- **模型集成治理：** 13 处 LLM 客户端收口为统一工厂，修复最坏 50 分钟等待（压至 2 分钟）；新老模型按端点自动分流、额度耗尽粘性降级、第三方模型采样参数自动修正；LLM 输出五级 JSON 解析 + 逐字段 normalize（缺评分不伪造 0 分）、按上下文支撑度提示幻觉风险（含量化假数据自动升级风险等级）。
- **工程质量与排障方法：** 272 项 pytest 离线零网络，重点测"故障时行为是否正确"（SSE 事件顺序契约、降级链粘性、题库游标并发）；修复过 SQLAlchemy 2.0 autobegin 事务缺陷（SQLite 内存库最小实验复现定位）、面试数据只 flush 不 commit 从未持久化、流式 ContextVar 跨 context 崩溃等问题——习惯用双端口对照、最小复现实验等手段把"疑似"变成"确定"。
